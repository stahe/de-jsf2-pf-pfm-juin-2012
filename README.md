## 📘 Überblick

Dieses Projekt begleitet einen Kurs zu folgenden Themen:

* **JavaServer Faces 2 (JSF2)**
* **PrimeFaces**
* **PrimeFaces Mobile**

Ziel ist es, eine vollständige Anwendung für die **Terminverwaltung** zu erstellen, die an verschiedene technische Umgebungen angepasst werden kann.

Dieses Dokument ist bewusst pragmatisch gehalten: Es stellt nur die Elemente vor, die für die Realisierung der untersuchten Anwendungen erforderlich sind.

---

## 🏗️ Entwickelte Anwendungen

Die Anwendung wird in den folgenden Umgebungen entwickelt:

1. **JSF2 / EJB3 / JPA** auf *Glassfish 3.1*
2. **JSF2 / PrimeFaces** (Version mit Ajax-Unterstützung)
3. **JSF2 / PrimeFaces Mobile**
4. Portierung jeder Version auf **JSF2 / Spring / JPA** auf *Tomcat 7*

➡️ Insgesamt: **sechs Java-EE-Anwendungen**.

## 🎯 Lernziele
